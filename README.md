## ◈ Project Overview

**Fluxora Studio** is a modern, high-impact digital agency and AI design studio landing page built around one philosophy:

<div align="center">

# "Technology Crafted for All, Not Machines."

</div>

It brings together cinematic visual storytelling, editorial typography, glassmorphic surfaces, interactive studio sections, and engaging project inquiry workflows.

The experience is designed to feel less like a traditional agency website and more like an immersive digital brand.

## ◈ Design Language

The Fluxora visual identity combines futuristic technology with a warm, editorial design language.

<div align="center">

| Color | Hex | Visual Identity |
|:---|:---|:---|
| ◼️ Obsidian Black | `#090909` | Depth & contrast |
| ◾ Charcoal | `#27201F` | Modern sophistication |
| 🟥 Vermilion | `#E94E3D` | Creative energy |
| 🟠 Warm Coral | `#FF735B` | Visual highlights |
| ⚪ White | `#FFFFFF` | Clarity & readability |

</div>

**Typography pairing**

- `Plus Jakarta Sans` — Bold, modern, geometric typography.
- `Playfair Display Italic` — Editorial personality and expressive accents.

**Visual principles:** Cinematic backgrounds, glassmorphism, generous whitespace, refined transitions, and strong typography.

## ◈ Interactive Experience

Fluxora Studio includes several interactive experiences designed to make the landing page more engaging:

**Features Dropdown:** Explore studio capabilities and their associated outcome metrics.

**Proof Modals:** Open detailed project and client-satisfaction information through interactive metric cards.

**Contrast Mode:** Switch the visual presentation in the studio section.

**Project Inquiry:** Open the project discovery form and validate client information before submission.

## ◈ Getting Started

Explore the project locally and continue development.

### 01 — Clone Repository

```bash
git clone https://github.com/GhousDeveloper/fluxora-studio-landingpage.git
```

### 02 — Enter Project Directory

```bash
cd fluxora-studio-landingpage
```

### 03 — Install Dependencies

```bash
npm install
```

### 04 — Start Development Server

```bash
npm run dev
```

### 05 — Production Build

```bash
npm run build
```
